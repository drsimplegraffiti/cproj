| Format Specifier | Description |
|-----------------|-------------|
| `%c`  | For character type |
| `%d`  | For signed integer type |
| `%e` / `%E` | Scientific notation for floating-point values |
| `%f`  | Floating-point (float / double in `printf`) |
| `%g` / `%G` | Floating-point with automatic format selection |
| `%i`  | Signed integer |
| `%ld` / `%li` | Long integer |
| `%lf` | Double |
| `%Lf` | Long double |
| `%lu` | Unsigned long |
| `%lli` / `%lld` | Long long |
| `%llu` | Unsigned long long |
| `%o`  | Octal representation |
| `%p`  | Pointer address |
| `%s`  | String |
| `%u`  | Unsigned int |
| `%x` / `%X` | Hexadecimal representation |
| `%n`  | Stores number of characters written so far |
| `%%`  | Prints a literal `%` |
