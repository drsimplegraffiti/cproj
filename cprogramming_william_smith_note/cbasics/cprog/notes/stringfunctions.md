| Function | Description | Syntax |
|--------|-------------|--------|
| `strlen()` | Finds the length of a string excluding the `'\0'` null character | `strlen(str);` |
| `strcpy()` | Copies a string from source to destination | `strcpy(dest, src);` |
| `strncpy()` | Copies `n` characters from source to destination | `strncpy(dest, src, n);` |
| `strcat()` | Concatenates one string to the end of another | `strcat(dest, src);` |
| `strncat()` | Concatenates `n` characters from `src` to the end of `dest` | `strncat(dest, src, n);` |
| `strcmp()` | Compares two strings lexicographically | `strcmp(s1, s2);` |
| `strncmp()` | Compares the first `n` characters of two strings | `strncmp(s1, s2, n);` |
| `strchr()` | Finds the first occurrence of a character in a string | `strchr(s, c);` |
| `strrchr()` | Finds the last occurrence of a character in a string | `strrchr(s, ch);` |
| `strstr()` | Finds the first occurrence of a substring | `strstr(s, subS);` |
| `sprintf()` | Formats and stores output in a string buffer | `sprintf(s, format, ...);` |
| `strtok()` | Splits a string into tokens using delimiters | `strtok(s, delim);` |
