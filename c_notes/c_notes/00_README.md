# Comprehensive C Programming Notes

This note set follows a full C course covering pointers, arrays, strings, dynamic
memory, structs, files, function pointers, bitwise operations, and more.

## Contents
1. `01_Pointers.md` — Pointers: basics, arithmetic, sizeof, advanced concepts
2. `02_Arrays_and_Strings.md` — Arrays, pointer-array relationship, strings, string library functions
3. `03_Dynamic_Memory.md` — malloc/calloc/realloc/free, dynamic arrays & matrices
4. `04_Structs_and_Architecture.md` — Structs, memory alignment, computer architecture basics, enums
5. `05_Function_Pointers.md` — Function pointers and callbacks
6. `06_Files.md` — Sequential and binary file I/O
7. `07_Preprocessor_and_Constants.md` — Macros, #define, const, project organization
8. `08_Bitwise_and_Algorithms.md` — Bitwise operators, bit fields, images/pixels, basic algorithms
9. `09_Debugging_and_Practice.md` — Debugging techniques, common pitfalls, practice problems

Read them in order for a structured path, or jump to the topic you need.
