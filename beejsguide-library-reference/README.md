# Local Layout

- `index.html` — full Beej's Guide to C Programming Library Reference (downloaded from https://beej.us/guide/bgclr/html/)
- `README.md` — this index/contents file
- `code/` — one `.c` file per code sample, named after its section (e.g. `11-4-demo-program.c`, `18-1-atomic-types.c`)

Build & run a sample:

    gcc -Wall -Wextra -std=c17 -o /tmp/lr_demo code/11-4-demo-program.c
    /tmp/lr_demo

Open the guide locally:

    xdg-open index.html
    # or
    firefox index.html

Section links inside the page work offline. External links (e.g. Wikipedia, beej.us) require an internet connection.
