# Local Layout

- `index.html` — full Beej's Guide to Networking Concepts (downloaded from https://beej.us/guide/bgnet0/)
- `README.md` — this index/contents file
- `code/` — code samples extracted from the guide (mostly Python/shell, some C). Named after the source HTML page (e.g. `introducing-the-sockets-api.py`, `project-digging-dns-info.sh`)

Build & run a Python sample:

    python3 code/introducing-the-sockets-api.py

Build & run a shell sample:

    bash code/project-digging-dns-info.sh

Open the guide locally:

    xdg-open index.html
    # or
    firefox index.html

Section links inside the page work offline. External links (e.g. beej.us, Wikipedia) require an internet connection.
